## 👥 Описание разделов и зон ответственности

### 🧔 [Андрей-ручки](./Андрей-ручки)
*Персональный раздел Андрея для проработки механики, органов управления и патентного анализа.*
* **Кому смотреть:** Андрей, инженеры по механике, юристы.
* [📁 общие вопросы](./Андрей-ручки/общие%20вопросы) — координация, базовые обсуждения.
* [📁 Патенты](./Андрей-ручки/Патенты) — патентные исследования, аналоги и заявки.

### 🌐 [Общее](./Общее)
*База знаний, техническая документация и общие исходные данные для всей команды.*
* **Кому смотреть:** Все участники проекта.
* **[📁 инфо](./Общее/инфо)** — технический архив проекта:
  * [Airbus A320 Documentation](./Общее/инфо/Airbus%20A320%20Documentation.md) — справочные материалы по самолету А320.
  * [Flight Controls - 27L3](./Общее/инфо/Flight%20Controls%20-%2027L3.md) — документация по системам управления полетом.
* [Сайдстики](./Общее/Сайдстики.md) — заметки и спецификации по органам управления (sidesticks).



### 📊 Корневые рабочие файлы
* [Диаграмма.svg](./Диаграмма.svg) — **главный граф/схема проекта**. Открывается в любом браузере или векторном редакторе.
* [Концепция](./Концепция.md) — верхнеуровневый документ с описанием сути проекта.
* [Таски](./Таски.md) — список текущих задач, спринты и дедлайны.
