
Определение исходных параметров для проектирования ручки 

Ручка должна соответствовать биомеханике человека

Занимает естественное положение 

Все функции управления должны быть доступны при управлении одной рукой, 
без необходимости перехвата, перемещения руки

Движения большим пальцем (управление скобой - аналог ручки общего шага) должны быть ограничены максимальным ходом среднестатистического человека, но в то же время должны быть минимально возможными, с сохранением точности управления

Кнопки (пока еще вопрос открытый с количеством выведенных кнопок на ручку управления), однако эргономические требования к  ним по госту - должны различаться по форме, цвету, для явного определения функций. Также должно быть исключено случайное нажатие кнопок. Расположение и количество кнопок - большой вопрос (на данный момент присутствуют в большом количестве кнопки разного назначения на обеих ручках). Соответственно от этого зависит и количество функций, которые выполняет ручка, для каждой функции необходимо описать требования.

Форма должна быть максимально эргономичной, во время длительных операций дискомфорт использования должен отсутствовать

Определить максимальные углы отклонения 

Необходимо минимизировать управляющие воздействия
