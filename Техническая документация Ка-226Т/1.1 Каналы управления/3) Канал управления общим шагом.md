#### Назначение
Канал управления общим шагом предназначен для передачи управляющего воздействия от рычагов общего шага через кинематику втулки НВ на лопасти НВ, вызывая одновременное изменение углов установки лопастей НВ на одинаковую величину.
#### Состав и размещение
Рычаги общего шага (ОШ) размещены в кабне экипажа слева от кресла каждого из членов экипажа.
Рычаг правого РОШ закреплен в хвостовике двумя конусными болтами и соединен качалкой через тягу. 
Канал управления общим шагом от качалки представляет собой цепь последовательно шарнирно соединенных элементов, размещенных под полом кабины экипажа в мотогондоле:
- В кабине пилотов (тяга → качалка на кронштейне → тяга → качалка → гибкая проводка управления. Качалка от правого РОШ через тягу и рычаг соединена с электромагнитным тормозом ЭМТ-3В, тягой с качалкой РОШ. Электромагнитный тормоз ЭМТ-3В предназначен для расфиксации РОШ при зажатой одной из гашеток управления фиксации левого или правого РОШ, а также их фиксации в новом положении после отпускания гашетки)
- В мотогондоле (гибкая проводка управления → КАУ-165М → качалка → тяга → качалка)

Все подвижные элементы в канале поперечного управления связаны между собой перемычками металлизациями, предназначенными для обеспечения выравнивания электрического потенциала между элементами управления НВ и фюзеляжем, с целью предотвращения искрообразований при возникновении электрических зарядов.
Датчики угловых перемещений МУ-616, установленный до КАУ-165 и МУ-616, установленный после КАУ-165М, предназначены для выдачи в систему "СУОВО" сигналов, пропорциональных перемещений РОШ и КАУ-165М соответственно и для записи в систему регистрации полетных данных.

#### Работа
Перемещение РОШ, передаваемое по каналу вышеуказанных элементов управления общим шагом, размещенных в кабине экипажа и мотогондоле, через кинематику втулки НВ воздействует на лопасти НВ, вызывая одновременное изменение углов установки лопастей НВ на одинаковую величину.
